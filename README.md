# Daily Sky

A phone app (PWA) that calculates a daily reading from astrology transits, Human Design gates and channels, numerology, BaZi (Four Pillars) and the I Ching, for any date.

- Everything is calculated in the browser. Birth data is typed in once and kept in the phone's local storage. It is never sent anywhere and is not in this repository.
- Planet positions come from [Astronomy Engine](https://github.com/cosinekitty/astronomy) (MIT licence), within about 0.01° of the Swiss Ephemeris. True node uses Meeus' series. Houses are Placidus.
- Works offline after the first visit. Install with Share → Add to Home Screen (iPhone) or the browser menu → Install app (Android).

Interpretations are traditional keywords. None of these systems has shown predictive power in controlled tests.
